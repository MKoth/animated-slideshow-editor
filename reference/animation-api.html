Animation API Cheatsheet

Quick lookup for keyframes, interpolation, clips, and evaluation.

Animatable Properties

type AnimationProperty =
  | 'positionX' | 'positionY'
  | 'rotation'
  | 'scaleX' | 'scaleY'
  | 'opacity'

ANIMATABLE_PROPERTIES       // all 6
BONE_ANIMATABLE_PROPERTIES // 5 (no opacity)

Camera: rotation not animatable. Bone: opacity not animatable.

Keyframe

class Keyframe {
  id: string
  time: number                    // seconds (0..slide.duration)
  value: KeyframeValue            // number | string | boolean | number[]
  interpolation: InterpolationType
  tangentIn:  { time: number, value: number }
  tangentOut: { time: number, value: number }
}

type InterpolationType = 'hold' | 'linear' | 'bezier' | 'bounce' | 'elastic' | 'spring'

snapshotOf(keyframe) → KeyframeSnapshot   // for inverse payloads

isParametricInterpolation(type) → boolean  // bounce, elastic, spring

  addMaterial(parameter, keyframe)

Evaluator

class AnimationEvaluator {
  evaluateNode(nodeId, time, scratch?): EvaluatedNodeState
  evaluateMaterialOverrides(nodeId, time, scratch?): MaterialOverrides
}

interface EvaluatedNodeState {
  transform: Transform   // evaluated local transform
  opacity: number        // evaluated opacity
}

ClipDefinition

class ClipDefinition {
  id: string
  name: string
  duration: number           // seconds
  category: string
  params: ClipParam[]        // user-adjustable scalars
  channels: ClipChannelDef[] // which properties it animates

  // Keyframe storage
  channelAnimations: Map<AnimationProperty, ClipChannelAnimation>
  materialChannelAnimations: Map<string, ClipChannelAnimation>

  // Access
  getChannelKeyframes(property): readonly Keyframe[]
  getMaterialChannelKeyframes(paramKey): readonly Keyframe[]
  getParam(key): ClipParam | undefined
}

interface ClipParam {
  key: string
  label: string
  kind: 'number' | 'color' | 'vec2'
  default: number
}

interface ClipChannelDef {
  property: AnimationProperty
  paramKey?: string              // link to a param
  linkMode?: 'gain' | 'offset'  // gain = multiply, offset = add
  materialParameter?: string     // target material param instead
}

ClipInstance

interface ClipInstance {
  id: string
  clipId: string
  startTime: number              // when it starts (seconds)
  speed: number                  // playback speed multiplier
  enabled: boolean
  paramOverrides: Record<string, number>
}

// Normalized time:
u = (time - startTime) * speed / clip.duration
u = clamp(u, 0, 1)

Composition Model

Layer 1: Static transform (node.transform) Layer 2: Keyframe evaluation (per channel, per property) Layer 3: Material tracks (per parameter, per node) Layer 4: Clip instances (per instance, per channel) → Final EvaluatedNodeState

Each layer overwrites the previous on the same channel. Clips that haven't started don't contribute.

Clip Channel Evaluation

kfValue = evaluateClipChannel(channel.keyframes, u)

if channel.paramKey:
  paramValue = instance.paramOverrides[param.key] ?? param.default
  if linkMode == 'gain':   output = base * (paramValue * kfValue)
  if linkMode == 'offset': output = base + paramValue * kfValue
else:
  output = kfValue
