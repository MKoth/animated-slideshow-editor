Transform

interface Transform {
  x: number          // offset from parent (px)
  y: number          // offset from parent (px)
  rotation: number   // radians, cumulative
  scaleX: number     // multiplicative
  scaleY: number     // multiplicative
  localPivot?: { x: number, y: number }  // rotation/scale origin
}

identityTransform()  → { x: 0, y: 0, rotation: 0, scaleX: 1, scaleY: 1 }
normalizeRotation(r) → r ∈ (-π, π]

World Transform

worldTransformOf(scene, nodeId)       → WorldTransform | null  (cached, lazy)
evaluatedWorldTransformOf(engine, id, t) → WorldTransform | null  (animated)
relativeTransform(world, parentWorld) → Transform | null  (inverse composition)

Composition formula (root → node):

x += rotateX(local.x * scaleX, local.y * scaleY, rotation)
y += rotateY(local.x * scaleX, local.y * scaleY, rotation)
rotation += local.rotation
scaleX *= local.scaleX
scaleY *= local.scaleY

NodeComponents

interface NodeComponents {
  camera?:        { kind: 'camera' }
  assetInstance?: { kind: 'assetInstance', assetDefinitionId: string }
  text?:          { kind: 'text', content: string, fontSize: number, alignment: 'left' | 'center' | 'right' }
  bone?:          { kind: 'bone', length: number }
  mesh?:          { kind: 'mesh', mesh: MeshData }
  ghost?:         { kind: 'ghost' }
  table?:         { kind: 'table', columns, rows, gap, cellPadding, borderWidth, borderColor, textWrap, columnMapping, cellSpans }
  chart?:         { kind: 'chart', chartType, dataSourceId, visualConfig, dataKeyframes, _dirty }
}

All component interfaces are Object.freeze()'d. Use copyComponents() to clone.

Scene

class Scene {
  id: string
  root: SceneNode
  camera: SceneNode

  getNode(id: string): SceneNode | undefined
  register(node: SceneNode): void     // adds to flat index
  unregister(nodeId: string): void    // removes from index
  toJSON(): SceneJSON
}

Dirty Flag Pattern

node._worldTransformDirty   // boolean
node._cachedWorldTransform  // WorldTransform | null

// On local transform change:
node.markDirty()  // sets flag + cascades to children

// On world transform query:
if (dirty) recompute(); else return cached
