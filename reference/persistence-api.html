Persistence API Cheatsheet

Quick lookup for autosave, recovery, and .lesson format.

PersistenceService

interface PersistenceService {
  save(): void                    // trigger immediate save
  onCommandSucceeded(): void      // called after every command
  dispose(): void                 // cleanup timers + listeners
}

createPersistenceService(deps): PersistenceService

interface PersistenceDeps {
  engine: EnginePublic
  upsert: (blob: string) => Promise<unknown>  // backend POST
  notify?: (message: string) => void
  ensureEmbedded?: () => Promise<void>         // embed assets before save
}

Backend API

// projectsApi.ts
ProjectsApi {
  upsert(blob: string): Promise<StoredProject>    // POST /api/projects
  list(): Promise<ProjectSummary[]>                // GET /api/projects
  get(id: string): Promise<string>                  // GET /api/projects/{id}
  delete(id: string): Promise<void>                 // DELETE /api/projects/{id}
}

interface StoredProject {
  id, name, description, author, created, lastModified, version
}

interface ProjectSummary {
  id, name, lastModified
}

.lesson File Format

{
  "version": 1,
  "project": {
    "id": string,
    "name": string,
    "description": string,
    "author": string,
    "created": string,
    "lastModified": string,
    "version": number,
    "slides": SlideJSON[]
  },
  "clips"?: ClipJSON[],
  "ikChains"?: { chains: IKChainJSON[] },
  "constraints"?: { nodeConstraints: Record<string, Constraint[]> },
  "library"?: {
    "assets"?: EmbeddedAssetJSON[],
    "materials"?: EmbeddedMaterialJSON[],
    "shaders"?: EmbeddedShaderJSON[]
  }
}

Serialization Pipeline

// Engine → JSON
engine.toJSON() → LessonJSON
  → JSON.stringify() → blob string

// JSON → Engine
validate(json) → string[]  (errors)
buildProjectFromJSON(json) → Project
parseClipsFromLessonJSON(json) → ClipDefinition[]
restore IK + constraints from json

Save Flow

Command succeeds → markDirty() → writeRecoveryShadow() (IndexedDB) → requestAutosave() (setTimeout debounce) → performSave() → ensureEmbedded() (fetch + base64 assets) → engine.toJSON() → JSON.stringify() → POST /api/projects → recordLastSaved() (IndexedDB) → markSaved()

Failure Modes

FailureBehavior
Backend downSave skipped, notification shown, editor keeps working
Network errormarkUnavailable(), next save skipped
Save in flightNew save queued (saveAgain), retried after
Tab closebeforeunload writes recovery shadow
CrashLast recovery shadow survives in IndexedDB
Tip: When debugging save issues, check: (1) is dirty true? (2) is backend available? (3) is saveInFlight blocking? (4) did ensureEmbedded fail?
