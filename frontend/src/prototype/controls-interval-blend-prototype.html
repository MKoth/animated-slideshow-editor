What this proves / what spec must fix

Verdict from this throwaway:
• 0…1 invariant reads instantly as ruler + proportional blocks; edge resize preserving stretch matches Clip Lane intuition (packClipLanesForNode geometry).
• Skip-outside + last-wins with [start,end) handoff (epsilon 1e-9, end==1 inclusive) feels correct — gap falls through to base track, no hold-last-value surprise.
• Blend as sibling Control (empty bindings, same ControlSet, key=blend→blend2) composes cleanly; recursive G1⊕G2⊕G3 as lerp(result12,G3,b2) with absent pass-through matches "closer to Group2 at 0.7".
• Morph delta lerp (lerpVertex absolute positions) is the right blend, not coefficient lerp — verified via differing shape pairs per group.
Spec must still lock: ControlBindingJSON string|{clipId,start,end}, ControlGroupJSON {id,name,bindings}, Control.blendKeys: string[], validator span≥1e-6, visible/zIndex rejection in any group, tolerant old-file decode → single group [0,1], ReusableObject shapeIdMap + clip-id remap, timeline AuthoringMode toggle (from #344).
