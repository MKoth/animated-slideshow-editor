What broke / what spec must fix

Prototype verdict: Loop holds — absolute snapshots + one active morph is scrub-babe. Bring to spec with:
  • Topology freeze must be hard-disabled in real meshEditInteraction.ts + Inspector banner (#271); no migration.
  • Brush accumulation: per-dab Transaction vs per-stroke — prototype uses per-dab preview + per-stroke commit; undo granularity needs product decision.
  • Screen↔world radius scaling at extreme zoom diverges; needs clamp at evaluateMeshDeformation call site.
  • 1.5 exaggeration can fold mesh; spec should clamp store 0..1, allow preview 1.5 only with warning.
  • UV/boneWeight inheritance: verified shared — no drift in prototype; add invariant test.
  • Large-mesh perf: brute-force O(vertices in radius) fine to ~5k verts at 60fps; >10k needs spatial index (follow-up).
