PROTOTYPE — research/shadow-silhouette

What this proves

  • BBox sizing: union worldAabbOf + pad ceil(blur*2+4) + max 2048, no Po2
  • Silhouette: clone+filter vec4(a,a,a,a) preserving soft edges; placeholder grey box casts; threshold alpha>0.01
  • Transform order: position→rotation→scale→skew pivot 0,0; degrees→rad at write
  • Filter: BlurFilter strength blur quality 2 kernel 5 (no Kawase)
  • Compositing: sibling-under addChildAt(indexOf(group)) with owningTable indirection; z sorts correctly
  • Dirty: two-tier (frame-hash + shadowDirty Set) post-morph-bones; RT reused when idle
Rendering: Silhouette via offscreen RenderTexture (combined alpha of source subtree, solid-white material), then transform → blur → tint/darken → composite beneath source. BBox-sized texture, dirty-flag per-frame regeneration. See research/shadow-silhouette-findings.md.
